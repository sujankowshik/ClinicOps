# **App Name**: Clinic Ops 2.0

## Core Features:

- Firebase Authentication: Secure user authentication using Firebase, including login and signup pages.
- Dashboard UI: Centralized dashboard for easy navigation to key modules.
- Patient Management: Register new patients and manage existing patient records.
- Appointment Scheduling: Schedule appointments, and view lists of upcoming and past appointments.
- Inventory Management: Track medical supplies with alerts for low stock, reorders, and shipment dates.
- Analytics Dashboard: Visualize key operational data to track performance metrics.
- FAQ & Triage Assistant: AI-powered tool using Gemini API and Genkit to answer common questions and triage complex queries for human support.
- Symptom Evaluator: AI tool that will use reasoning to determine the need to use patient symptoms, age, and other details to provide potential diagnoses and assess severity.

## Style Guidelines:

- Primary color: Deep Blue (#2962FF) to inspire trust and confidence in medical data.
- Background color: Light Blue Gray (#E0E5F1), almost desaturated but still a blue hue, for a calm, professional look.
- Accent color: Violet (#7A3FF2) to highlight interactive elements and key information.
- Headline font: 'Space Grotesk' sans-serif. Note: currently only Google Fonts are supported.
- Body font: 'Inter' sans-serif. Note: currently only Google Fonts are supported.
- Consistent, clear icons from ShadCN UI to represent various features and data points.
- Responsive layout using Tailwind CSS grid and flexbox to ensure optimal viewing across devices.
- Subtle animations for transitions and interactions to enhance user experience without being distracting.
